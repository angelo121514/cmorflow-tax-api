## Cobertura estructural pendiente

- Hay tablas con consumidores de dominio pero no rutas propias: tenants, tenant_configs y sii_submissions.
- cron_nonces es infraestructura, no entidad de feature.
- audit_logs puede registrar acciones de varias features, pero no tiene endpoint de consulta en este proyecto.
- Envíos SII y requests se conectan por TrackID/vínculo de aplicación; revisar al cambiar persistencia.
- No se encontró API para alta tenant/tax profile, ni flujo de administración tributaria completo.
