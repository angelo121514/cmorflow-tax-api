# Modelo de amenazas

Revisión de fuente 2026-10-13 sobre a2aef05. No es pentest ni inspección de producción. Activos: credenciales, PFX/CAF, folios, documentos tributarios, datos por tenant y evidencia de entrega.

Flujo: integrador → HTTP/HMAC → solicitudes PostgreSQL → worker → firma/SII → estado y artefactos → webhook externo. Cada flecha cruza una frontera de confianza; HTTP y worker deben fijar tenant y permisos antes de acceder a datos. SII y destinos webhook son respuestas externas no confiables.

| Frontera / amenaza                                                | Control observado y evidencia                                                                                                                                                             | Riesgo residual / seguimiento                                                          |
| ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| HTTP: suplantación, replay, privilegios                           | [Guard HMAC](../../src/infrastructure/guards/integration-hmac.guard.ts), [pruebas](../../src/infrastructure/guards/integration-hmac.guard.spec.ts); timestamp, nonce, firma y permisos    | No acredita rotación ni configuración de secretos en producción                        |
| PostgreSQL: IDOR o cruce de tenant                                | [E2e PostgreSQL](../../test/postgres.e2e-spec.ts), [seguridad](SECURITY.md)                                                                                                               | Auditar nuevas rutas y roles de despliegue; privilegios remotos desconocidos           |
| Worker: doble reclamo o caída entre pasos                         | [Claimer](../../src/application/integrations/integration-queue.claimer.ts), [processor](../../src/application/integrations/integration-processor.service.ts)                              | Reserva/vínculo no atómicos: TASK-002; configuración obsoleta: TASK-001                |
| PFX/CAF: exfiltración, corrupción, folio reutilizado              | [AES](../../src/infrastructure/framework/crypto/aes-256-cipher.ts), [configuración](../../src/infrastructure/framework/sii/tenant-config.service.ts)                                      | Custodia/rotación del master key requiere operación; concurrencia TASK-001             |
| SII/XML: respuesta inválida, reglas incorrectas, reenvío          | [Reglas](BUSINESS_RULES.md), [decisiones](DECISIONS.md); observed conserva TrackID                                                                                                        | Mocks no certifican XML/firma/T46: TASK-005                                            |
| Artefactos: lectura entre tenants o token filtrado                | [Servicio](../../src/application/integrations/integration-artifacts.service.ts), [pruebas](../../src/application/integrations/integration-artifacts.service.spec.ts)                      | Enlaces bearer requieren proteger logs y expiración; configuración remota no examinada |
| Webhooks: SSRF, respuesta lenta, falsificación, pérdida de evento | [Servicio](../../src/application/integrations/integration-webhook.service.ts), [pruebas](../../src/application/integrations/integration-webhook.service.spec.ts); firma y consumo acotado | Revisar restricciones de red en despliegue; falta outbox transaccional: TASK-003       |
| Provisioning: tenant o perfil incorrecto                          | [Precondiciones](TENANT_PROVISIONING.md)                                                                                                                                                  | Sin procedimiento aprobado: TASK-004                                                   |

Prioridad, responsables, dependencias y evidencia de cierre están en [TASKS](TASKS.md). Un control en fuente o un test aprobado no demuestra su eficacia en todos los ambientes.
