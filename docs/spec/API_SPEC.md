# Especificación de API observada

## Convenciones

- Base REST: /api/v1. Swagger: /api/docs si activo. Formato principal JSON.
- **HMAC B2B:** X-Api-Key, X-Timestamp, X-Nonce y X-Signature; query string forma parte de la firma. OpenAPI declara estos cuatro requisitos AND y el permiso por operación en `x-required-permissions`.
- **Cron HMAC:** X-Cron-Timestamp, X-Cron-Nonce, X-Cron-Signature con CRON_HMAC_SECRET y body crudo.
- **Público/token:** una ruta marcada sin HMAC de API no implica ausencia de control; artifacts usa token firmado.
- DTO se valida con whitelist global y propiedades extra se rechazan.
- Los códigos exactos de todos los errores no están anotados por ruta. Tabla de abajo combina errores explícitos de controller/service y el filtro global; no inventa esquemas de respuesta donde no los hay.
- OpenAPI documenta 27 paths y 31 operaciones; cada operación declara security (vacío para rutas públicas), permisos, schemas de éxito y errores. `npm run openapi:check` comprueba drift y completitud. `/metrics` está excluido intencionalmente de Swagger.
- `Idempotency-Key` se exige en emisión DTE/notas y RCOF; es opaca y no vacía, no requiere formato UUID. Se persiste como `varchar` sin longitud máxima definida por la aplicación; rigen los límites del servidor HTTP y almacenamiento.

### DTO de DTE y nota

documentType estándar: 33/34/39/41/46/52. Receptor contiene rut, name y giro/address/commune opcionales. Cada item: name máx. 80, quantity >0, unitPrice >=0, exempt, discountPercentage, discountAmount. Máx. 1000 ítems. Nota requiere reasonCode/reason y items. El DTO permite totales declarados parciales.

### DTO RCOF

date debe ser fecha ISO válida. sequenceNumber es entero >=1, default 1. Lógica de dominio valida forma YYYY-MM-DD, idempotencia real de submission es tenant+fecha+secuencia.

## Errores transversales

IntegrationErrorCode incluye API_DISABLED, MISSING_HEADERS, UNKNOWN_KEY, CREDENTIAL_REVOKED/EXPIRED, TIMESTAMP_OUT_OF_WINDOW, INVALID_SIGNATURE, NONCE_REPLAYED, RATE_LIMITED, PERMISSION_DENIED, TENANT_MISMATCH, IDEMPOTENCY_KEY_REQUIRED/CONFLICT, VALIDATION_ERROR, TOTALS_MISMATCH, EXTERNAL_REFERENCE_CONFLICT, FOLIO_EXHAUSTED, SII_REJECTED/UNAVAILABLE, INVALID_STATE_TRANSITION y NOT_FOUND.

GlobalExceptionFilter da estructura con statusCode y error; errores no tipados pueden ser INTERNAL_ERROR. QueryFailedError 23505 se detecta por texto de mensaje y otros errores DB responden DB_ERROR. Status codes de todos los errores no están declarados formalmente por operación. El catálogo de código estable está en src/application/integrations/integration-errors.ts.
